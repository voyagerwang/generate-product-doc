# 飞书局部修改安全示例

## 正确做法

当用户要求“只修改 5.3.4.8 的抢麦进行中和抢麦结束态”时：

1. 先读取文档标题树，定位 `5.3.4.8`。
2. 再读取该章节下的目标表格，确认表头、行名和现有内容。
3. 只替换目标行的 `元素` 与 `逻辑说明` 单元格。
4. 写入后回读该章节，检查：
   a. 目标行内容已更新。
   b. 其他行没有变化。
   c. 表格列没有串位。
   d. 有序列表仍是飞书原生序号。

## 禁止做法

1. 删除整张表后重建。
2. 删除整章后重写。
3. 为了调整一行内容顺手整理其他章节。
4. 无法确认单元格写入能力时仍强行写入。
5. 把飞书原生序号降级成普通文本 `1.`。

## 无法安全写入时

如果工具无法保证保留表格、图片或原生列表格式，输出以下内容：

1. 明确说明无法安全局部写入的原因。
2. 给出目标章节标题。
3. 给出可直接粘贴的内容。
4. 等用户确认后再继续。
